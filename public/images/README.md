# Image files

Add or replace your images using these exact filenames:

- `branding/enterprise-logo.png` — main EnterpriseGPT logo
- `avatars/user-avatar.png` — signed-in user profile photo
- `agents/hr-agent.png` — HR assistant avatar
- `agents/it-agent.png` — IT support assistant avatar
- `agents/finance-agent.png` — finance assistant avatar
- `agents/sales-agent.png` — sales assistant avatar
- `agents/default-agent.png` — fallback assistant avatar
- `backgrounds/login-background.jpg` — optional large background image

Recommended sizes:

- Logo: 256 × 256 PNG with transparent background
- User and agent avatars: 256 × 256 square PNG or JPG
- Background: 1920 × 1080 JPG

Keep the filenames exactly as listed so the UI can reference them from
For example: `/images/agents/hr-agent.png`.
